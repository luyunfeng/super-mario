# 主线功能与验收矩阵

当前交付以 G01–G24 主表、验收报告开头及最新证据为准。本地单元与集成测试、双向插件 AST 边界检查、类型检查、Chromium 浏览器端到端测试、构建及编译安装包冒烟均已通过；真实外部未验项（飞书真实账号收发与跨物理机器联调）明确保留边界。

## 1. 工作台核心体验补充

| 体验 | 已实现及代码地图 | 验收与剩余边界 |
| --- | --- | --- |
| 主对话与项目代码侧栏 | `features/code-sidebar.js` 共用组件；`GET /projects/:id/code` 只读取保存的电脑绑定；执行机 `plugins/workspace-code.ts` 提供目录、UTF-8 文本及相对 HEAD 的已跟踪文件 diff | 真实本地独立代理/HTTP/WS；根目录、路径和软链接越界、凭证文件及别名、二进制、256 KiB 上限均验证；未接真实远端电脑；无代码编辑 |

## 2. G01–G24 主线能力矩阵

知识、待办、外部 Agent 是业务主线；项目组织持续目录与工作范围，机器、Run、会话、信箱和事件复用现有模型。机器人是可选渠道身份，插件是扩展机制，不把它们重新定义成外部 Agent。全局知识仍是工作原则，实时态势从有权限的共享事实读取。

| ID | 本产品用户场景与实体映射 | 当前实施状态 | 完成证据要求 |
| --- | --- | --- | --- |
| G01 | 主 Agent 每轮知道项目、待办、Run 和决定 | 共享快照与执行者/会话/阻塞关联已补；真实主模型调用 `runs_list` 读取合成存储事实、区分未知与待决定且零业务写入，独立 CLI 见 G03 | 真实存储更新后即重读；范围先过滤；未知不当完成 |
| G02 | 跨 Web/机器人接续工作决定 | 已接工作决定修订账本、Web 新增/编辑/撤回、每轮上下文及引用工具；跨渠道来源以本地替身验收 | 跨入口引用同一决定，纠正令旧决定失效，不合并私有原始聊天 |
| G03 | 外部 Agent 发现、配置和可用性 | 元数据/父子线程只读投影、launcher/profile、历史隔离和按需凭证诊断已接通；当前机 Codex 任务、自主发现选择与原生结果已验 | 元数据只读发现、稳定原生标识、来源/新鲜度；不可把 PATH 当登录 |

| G05 | 执行原生结果、持续进展、阻塞 | 结构化阶段、固定线程/来源校验和真实阻塞已接通；原生结果、文件字节核验及不重派证据已备，跨物理机器仍待验 | 原生来源、执行者/会话/事项关联；未知/未上报明确；无假完成 |
