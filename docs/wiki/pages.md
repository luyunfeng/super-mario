# 从前端找功能：九个入口怎么用

新用户先看首页，再按手里的事情选入口。下表按桌面侧栏实际顺序排列；「插件配置」和顶栏工具另外列在表后。

| 页面 | 到这里做什么 | 下一步看哪里 |
| --- | --- | --- |
| 首页 | 「需要我」集中列提问、确认、批准或验收；「重要紧急」看逾期和未来 24 小时的待办。 | 从事项进入详情。简报里的“完成待办”和“执行结束”分别统计。初次使用可展开动态图解。 |
| 对话 | 问跨项目问题。用「会话状态」看待决定项，「搜索本对话」找旧约定，「查看代码」看项目文件。 | 需要正式文件时开「办公文件」，填标题和源内容，选择 Word、PowerPoint 或 Excel，再核对生成文件。 |
| 消息 | 查你与机器人的独立对话，可切「进行中」「已归档」。 | 要延续某个机器人的上下文，打开原会话。首次为空时先完成飞书私聊配对。 |
| 收件箱 | 先按私聊、群@我、群聊或 Agent 协作找来源，再按待人决策、待 AI 执行等状态定位。 | 打开原文；需要交付就转待办，需要答话就拟回复，需要保留判断就记结论。「多选」支持批量转待办或归档。 |
| 发件箱 | 从状态筛选「待确认」或「失败或结果未知」。 | 核对发送对象、内容和回执。有疑问先回原会话查是否送达。 |
| Agent | 配模型、接电脑、管理技能、调跟进节奏、设定时工作。 | 模型处理对话，执行器在指定电脑动手。模型已配置但电脑数为 0 时，先点「添加电脑」。 |
| 项目 | 从电脑添加目录，或在「全部」查看汇总待办和执行。 | 工作区讨论目标，待办记录承诺，执行详情核对本轮产物。列表可切日历；工作区看板可切手工列或自动分组。 |
| 记忆 | 写下长期背景，设置整理队列，查询会议日回顾，登记工作决定。 | 新资料看队列；长期约定看所属知识页；需要知道哪一版决定有效，查看工作决定记录。 |
| 渠道 | 连接机器人、个人飞书、GitHub 或邮箱，把消息引入系统。 | 收到的看收件箱，主动发出的看发件箱；需要按身份查已发内容时看「以我的名义发出的」。 |

## 容易错过的入口

**插件配置。** 侧栏底部可查看具体插件用途和启停状态。功能灰掉时，先检查插件状态，再检查账号授权或电脑是否在线。启停作用于整个工作台。助手技能属于另一层，在「Agent → 助手技能 → 管理技能」查看，内置工作指南和办公文件技能分别处理任务跟踪和文件生成。

**顶栏。** 「全部项目」是当前范围；快速建待办前先看这里。「多屏现场」适合同时观察执行机终端。「上下文透视」用于追查助手在当前工作中看到了什么。想找一次历史执行时，可在顶栏搜索框组合项目名、状态和时间，例如 `state:running since:7d`。

**GitHub 和邮箱。** 在「渠道 → GitHub」选择已登录 gh 的电脑，勾选读取未读通知并保存。先用「立即检查」看账号和结果，再用「哪些通知进收件箱」过滤分支或静音仓库。「渠道 → 邮箱 → 添加邮箱」需填邮箱地址和密码或授权码，必要时展开服务器和加密方式；添加后先检查连接和文件夹，再开启未读邮件入箱。同话题可聚合，工作台只读收取不会把邮件标为已读。
