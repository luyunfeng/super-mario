## 5. 修复过的验收缺陷

- 真实自定义执行者未被调用：由真实 Codex CLI 修改，统一走 Executor.execute；9 项新增契约测试与主线程集成回归通过。
- 任务范围策略在补入项目事实后可能不命中：增加任务独立范围继承，并由真实执行记录派生上下文，模型不能伪造较弱策略范围。
- 真实终端 CLI 不接受 `--cwd=/path`：改为参数和值分开传递，并用真实 Codex 链路回归。
- 同一飞书消息并发到达可能重复提交：增加接收认领和持久记录。
- 配置切换、关闭或停用时旧采集结果可能继续入库：增加生命周期隔离。
- 原始任务结果可能被初始回复关联逻辑消费：分离结果回送，并按动作标识去重。
- 最小审批带缺省字段时被错误标成失败：回执改为明确的 runId。
- CLI 退出后控制台消失：任务模式保留终端外壳和画面，交互模式仍保持退出后不可误写 shell。
- 任务模式不接收交互输入：服务端和执行节点拒绝，页面禁用输入并保留观察、中断。
- 节点 handler 错误不可诊断：返回脱敏原因；同连接重复 RPC 不重复执行。
- 重启后待处理对话可能一直显示处理中：明确提示结果未确认，不自动重派。
- 连接关闭回调可能访问已关闭数据库：先清理连接及后台工作，再关闭存储。
